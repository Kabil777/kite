# Icon artwork

## Gopass mascot

`gopass.png` is the unmodified PNG distributed as [`docs/logo.png`](https://github.com/gopasspw/gopass/blob/master/docs/logo.png) by Gopass. It identifies the Passwords/Gopass integration; it does not imply endorsement of KITE.

- Gopass Gopher adaptation: **Vincent Leinweber**, as credited in the [upstream README](https://github.com/gopasspw/gopass/blob/master/README.md).
- Original Go gopher: **Renée French**. The [Go project's attribution and licensing statement](https://go.dev/blog/gopher) identifies the original gopher images as [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
- Upstream Gopass repository license: [MIT](https://github.com/gopasspw/gopass/blob/master/LICENSE), reproduced below.
- PNG SHA-256: `689b9460d9f815a717ab4316da28b05554f2d34a95c6889804284d7eb423b71a`.
- No edits to the artwork. Qt scales it proportionally for display. No runtime image downloads occur.
